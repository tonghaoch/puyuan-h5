# 定位平滑与配准修正

本次应用改动包含短时设备读数平滑，以及已确认的 S1/S2 错桥配对修正。地图仍使用 23 个观察控制点的三角网；其他离线候选没有接入应用。

## 应用行为

`src/lib/location-smoothing.ts` 在当前监听的内存中保留最近 2.5 秒内最多五条设备读数，按时间和设备报告精度加权。输出与最新原始读数的距离最多三米，时间戳仍是最新样本的时间，估计范围加上平滑位移。相邻读数变化超过十二米、采样中断、过期、出错或重启时重置。

合成静止轨迹 RMS 由 3.37 米降到 2.38 米。该结果仅验证小幅抖动处理；持续 GPS 偏移和孤立大跳点仍不能从相同读数中识别或消除。监听不存储或上传轨迹，更新不移动相机或弹出页面。

配准修正固定于 `references/geodata/registration-release-07.json`：

- S1：卫星 `[259,1044]` 对应场景 `[257,1059]`，纠正相邻东西桥混配。
- S2：卫星 `[536,921]` 对应场景 `[600,943]`，纠正原图桥面与另一街区混配。

西庙桥 V3 的同源影像几何偏差约 6.93 → 3.16 米。原显示约束、排除区、170 像素支持阈值和 16 米配准估计量保留，额外校验原版显示范围。这个单点结果不能证明整段或全园实际定位精度。

## 工具与完整评估

`scripts/register_illustration.py` 核验原始观察、旧模型、两份更正记录、实际底图及场景配置的 SHA-256，精确重建当前应用模型。检查点变化只影响报告；未经记录的输入变化和覆盖无关模型改动会被拒绝。`--write-model` 才写应用模型。

三角网生成器过去会遗漏近共线凸包三角形。现在比较三角形总面积与凸包面积，必要时扩大初始化包围三角形，无法恢复或输入退化时明确失败。最小回归案例 `[[259,1044],[893,960],[948,953]]` 的两倍面积为 182；六种顺序均保留完整三角形。该修复不改变本次应用模型。

检查资料保留原 trial 记录；K4/V6 根据源图重新辨认桥面后的观察分别在 `bridge-reobservation-11.json`、`bridge-reobservation-12.json`，仅用于评估。原值保留在报告中，未作为新控制点，也不是新盲测。历史 trial 脚本及数据用于复现来源和回归测试，不表示其候选已采用。

当前完整 17 条观察：**10 条名义误差 <10 米、2 条 ≥10 米、5 条无法测量**。

| 异常或空白 | 当前结果 |

| F3 方院西南路口 | 名义 18.15 米，精确共享路心未证。 |

## 复现

Python 工具需要 Pillow；Node 版本见项目 `.nvmrc`。

```sh
npm test
npm run build:review
npm run location:review
node scripts/review-registration-release.mjs
node scripts/review-location-smoothing.mjs
```

生成的模型、完整检查与运行时显示报告位于 `artifacts/location-calibration/release-07*`；合成轨迹对照为 `device-filter-06.html/json`。报告和缓存不加入发布包，来源影像的研究使用边界沿用[地理数据说明](../references/geodata/README.md)。

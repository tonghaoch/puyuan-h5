## 验收规则

1. 每区按对象 ID 领取写入范围；同一对象只有一个负责人。只改作者数据及明确分配的专用画法，不提交、公用目录不并发写。原图只用于观察、定位及离线验收；不嵌图、贴纹理、从误差描补或按标签边缘画形状。GPS、POI、纸图登记、阈值与遮罩不变。
2. 负责人交作者文件、对象 ID、图面依据和已知退步。主 session 从原生素材重测，不采用负责人自报的小窗分数。验收工具始终使用主仓固定协议：

   ```sh
   python3 scripts/review-park-alignment.py --root "$CANDIDATE" --compare-root "$FROZEN_BASE" --out "$REPORT" --diagnose
   ```

3. 报告检查目标区、邻区、八像素接缝、19 个固定窗和全园。`changedDarkPixels` 区分纠正与新增错误，避免同分掩盖邻区重画。未申报的越界变化要查明；图面构造不实、目标区或全园净退步的候选退回，不靠截好看的小窗通过。
4. 只合入经核对的作者文件，重新生成完整主图；不接收 worker 的 SVG、WebP、生成清单或自改验收脚本。合并版复查四区与接缝、原图/成图目视、项目回归、无原图重建和双端实屏。其他窗口的退步如实登记。局部修正可接收为「进展」，但不到 `0.85` 不标该区达标；全园用四区交集之和除以并集之和，不取四区分数平均或不同时刻的最佳值。

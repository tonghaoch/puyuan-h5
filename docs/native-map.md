# 独立原生手绘导览

目标：手绘导览可完全取代原图；所有地形、建筑、植物、桥梁、装饰和文字均由项目自身的可编辑数据与绘制代码生成，整体细腻程度高于参考图。

## 完成条件

1. 手绘导览、地点详情图与水面动画均不包含参考图像素。原图仅在主动选择对照视图时加载。
2. 地面、水系、铺装、桥梁、驳岸、植物、灯笼、船只与设施均有独立几何或实例数据；可以单独修改、重绘。
3. 19 个地标组团及所有街巷建筑都有完整的原生形体与材质。原图文字下方的区域用连贯的风格化设计补全，标注改由清晰的原生文字与交互点位呈现。
4. 原图只约束总体布局、组团区别和可见形体。补全的不可见细部属于美术设计，不作为实测建筑或 GPS 依据。
5. 日常素材重建无需原图或网络；导览请求屏蔽所有原图衍生资产时仍完整可用。
6. 对全园和全部 19 处建筑做桌面、手机和高缩放图像检查，确认原有水路、街巷、院落、桥梁关系保留，并检查更细的瓦面、木构、植物和装饰。仅通过功能测试不能证明视觉目标完成。
7. 建筑点选、拖动缩放、目录、外围探索、动画暂停、三 tab、详情与定位视图通过回归。

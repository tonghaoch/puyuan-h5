# 当前实现

更新：2026-11-18。交付形态已明确为「具有微信小程序布局的 H5 网页」。

## 手机布局与交互

- 全部屏幕宽度采用同一套手机界面；电脑居中预览，最大宽度 480 px。
- 紧凑顶部栏、固定底部三个 tab、顶部与底部安全区。
- 详情由底部弹出，支持手柄下拉关闭、关闭按钮、浏览器返回、键盘焦点约束与恢复。
- 地图拖动、双指/滚轮缩放、缩放按钮、视野重置；切 tab 和地图视图保留对应镜头。
- 餐厅/活动分类与搜索、场次状态、收藏、列表和地图联动继续可用。
- 水纹、游船、灯光、飞鸟与花瓣动画；切后台、离开地图或打开弹层后暂停。支持减少动态效果。

## 四种地图视图

| 视图 | 底稿 | 点位与定位 |
| --- | --- | --- |
| 手绘导览 | 用户原图古镇范围，保留可见建筑、河道、桥梁、岛块和原标签，统一青绿配色 | 18 处参考图地点；活动与餐厅为演示内容；无 GPS 点 |
| 原图对照 | 同一古镇范围的原始配色 | 与手绘导览共用同一图像坐标、地点及镜头，可检查位置是否挪动 |
| 真实路网 | OSM 原始边界、道路、桥和水道中心线 | 8 个原始具名地标；以 WGS84 → Web Mercator 显示 GPS 与精度范围 |
| 影像核对 | Esri World Imagery 单张导出 + OSM 叠加 | 用服务返回的 EPSG:3857 extent 放置影像，与路网/GPS共用投影 |

### 原图还原方式

初版曾使用通用建筑程序排列，未忠实对应原图。这版已替换为**原图衍生底图**：只做范围遮罩、整数平移和配色处理，没有重新排列建筑、扭曲河道或根据想象补桥。

原始参考图始终保留。scripts/prepare-reference-map.py 生成手绘色彩版、原色对照版、水面动画遮罩；src/data/reference-map.json 保存范围、多点位置、统一平移量和水面动效路径。docs/map-asset-manifest.json 记录源文件 hash 与处理方式。原图标签覆盖的建筑细节没有被臆造补齐。

已补全游客中心、水上舞台、北更楼、濮驸马第、福善寺、禅美术馆、禅意酒店、设计师之家、翔云观、濮商会馆、梅泾剧场、深夜食堂、书场、大有桥建筑群、濮家大院、妆楼、龙湾街美食广场、美食中心。

这完成了参考图可见布局和细节的保留，**不是重新建立全部建筑三维模型**。初版卡片上的装饰插画继续保留；原程序地图已移入 references/previous-prototype-map.svg，不再随网站发布。

### 真实地理资料

公开底稿包括一个园区 polygon、125 处道路/广场（含29条桥 way）、15 条水道中心线、一栋建筑与8个具名 POI。没有用地图交叉线段猜测桥或道路连接，没有把缺失的建筑 footprint 补成“实测数据”。

参考图中的“福善寺”与 OSM 的“福山寺”名称不同；游客中心标签也不等同于入口测点。每个视图保留自己的来源名称，未将未确认对应关系的活动 pin 移到地理图上。

影像来自一次官方 MapServer export，按实际返回 extent 对齐，而不是使用请求时的 bbox。地理视图保留 OSM 署名及 Esri/Vantor/Earthstar/GIS User Community 来源说明。影像是本地核对快照，不是实时卫星图。来源记录见 map-reconciliation.md。

## 定位与失败处理

用户主动获取位置，使用浏览器 Geolocation，位置不上传也不持久保存。拒绝、超时、不支持、精度不足与过期都有独立处理。

获取后可以直接选择「在真实路网中查看位置」，在主地图查看用户点和精度范围，切换影像保持对齐。用户远离地图范围时明确提示，不把定位点放到园区边缘。精度范围跨园区边界时不武断判定园内或园外。

手绘图仍是透视插画，未完成地面控制点配准；不会把 GPS 直接贴到手绘图。微信 JS-SDK 和签名后端尚未配置，目前使用浏览器定位；手机联调需 HTTPS 和系统位置权限。

## 维护与验证

- npm run art:reference：从原始参考图重新处理主地图，需要 Pillow。
- npm run art:generate：重建卡片插画与主地图。
- npm run geo:package：从保存的公开数据快照重建发布用 GeoJSON 和地标清单，不修改几何。
- npm test：时区、场次、镜头、地理位置状态、参考图布局关系、影像坐标变换。
- npm run test:e2e：桌面/手机尺寸下的导航位置、搜索收藏、手势、弹层、四种地图视图、GPS 与图层隔离。
- npm run build：类型检查和生产构建。

自动化使用 Chrome 与模拟设备坐标；不代替 iOS/Android 微信真机、景区现场或测绘精度验收。活动、营业时间、餐厅价格仍为演示数据。

# 当前实现

当前 H5 只提供导览。设备定位只在「我的位置」中显示，不叠加在导览上。以下原生场景和影像核对记录为早期开发资料；现行导览说明见 [README](../README.md)。

## 当前方向：独立原生手绘

用户目标已更新为：手绘导览完全取代原图，所有内容原生实现，整体细腻程度高于原图。验收条件与未完成项见 [原生手绘目标](native-map.md)。

已接入独立的原生地形、水系、驳岸、石铺地、桥梁与植物图层；原图印刷标签已移除，遮挡区改用可编辑的原生房屋设计。主图、动画遮罩及详情场景不再合成原图像素。全部 SVG 可编辑，预渲染图片由这些 SVG 生成。原图仅在主动选择对照视图时使用。

`town-landscape.json`、`town-architecture.json` 与 `town-completions.json` 是绘制输入；普通素材重建无需参考图片。旧轮廓转写仍有建筑分面和立面不足、个别水岸碎边、补全区比例与桥梁衔接待校正。现在仍处于原生精修中，尚未通过“全园精细程度超过原图”的视觉验收。

## 当前新增：构件细化

全园表面增加瓦当、檐影、窗框、木格和墙脚，并从原图保留坡面明暗与木构长线条。接续修正了北更楼的木构楼阁与石台形体、妆楼高立面的位置，以及设计师之家两座长屋的双坡；酒店内院和寺塔也补充材质层次。详情图合成相邻建筑层。见 [全园构件细化](architecture-finishing.md)。

建筑图片与细赏状态移除了会导致放大模糊的 CSS 阴影滤镜，材质明暗由素材本身提供。

## 手机布局与交互

- 水纹、游船、灯光、飞鸟与花瓣动画；切后台、离开地图或打开弹层后暂停。支持减少动态效果。

### 原图还原方式

初版使用通用建筑程序排列，后来使用原图衍生底稿；当前正在替换为**独立原生场景**。水系与可见建筑的总体布局以参考图转写几何为依据，材质、景观、补全区和植物由代码绘制，标签已改为可交互点位。补全区属于美术设计，不作为实测建筑或原图遮挡内容的事实还原。

原始参考图保存在研究资料中。`prepare-reference-map.py` 仅生成可选对照图；`generate-landscape.py` 从几何生成地形、水面遮罩与植物；`generate-landmarks.py` 从独立建筑数据生成建筑，`finalize-architecture.py` 合成原生场景详情图。

已补全游客中心、水上舞台、北更楼、濮驸马第、福善寺、禅美术馆、禅意酒店、设计师之家、翔云观、濮商会馆、梅泾剧场、深夜食堂、书场、大有桥建筑群、濮家大院、妆楼、龙湾街美食广场、美食中心。

当前保留了原图的总体布局，并完成19个独立组团和街巷建筑增强层，**不是全园建筑测绘或完整三维模型**。初版卡片上的装饰插画继续保留；原程序地图已移入 references/previous-prototype-map.svg，不再随网站发布。

### 真实地理资料

公开底稿包括一个园区 polygon、125 处道路/广场（含29条桥 way）、15 条水道中心线、一栋建筑与8个具名 POI。没有用地图交叉线段猜测桥或道路连接，没有把缺失的建筑 footprint 补成“实测数据”。

参考图中的“福善寺”与 OSM 的“福山寺”名称不同；游客中心标签也不等同于入口测点。每个视图保留自己的来源名称，未将未确认对应关系的活动 pin 移到地理图上。

影像来自一次官方 MapServer export，按实际返回 extent 对齐，而不是使用请求时的 bbox。地理视图保留 OSM 署名及 Esri/Vantor/Earthstar/GIS User Community 来源说明。影像是本地核对快照，不是实时卫星图。来源记录见 map-reconciliation.md。

## 定位与失败处理

可见的导览页自动通过浏览器 `watchPosition` 请求定位；离开地图或进入后台时清除监听与坐标，返回后恢复。每次进入页面的会话中，拒绝后只允许用户手动重试。位置不上传也不持久保存。超时、接口不支持、精度范围跨边界及超过 60 秒的读数均不会被当成当前园内点。模拟步行预览不申请真实定位。

点定位键不切换页面、不抢占镜头；检测到人在园内时，地图角落的园区边界小图显示实时点和精度圈，再点定位键收起。园外、边界不确定或定位失败时只显示文字，不把点放到园区边缘。

手绘图仍是透视插画，未完成地面控制点配准；不会把 GPS 直接贴到手绘图。微信 JS-SDK 和签名后端尚未配置，目前使用浏览器定位；手机联调需 HTTPS 和系统位置权限。

## 维护与验证

- npm run art:reference：仅重建原图对照，需要原始图片和 Pillow。
- npm run art:generate：从保存的原生数据重建卡片插画、主地图、图层与场景，无需原图。
- npm run geo:package：从公开数据快照复制发布用园区边界并保留署名，不修改几何。
- npm test：时区、场次、镜头、地理位置状态、参考图布局关系、影像坐标变换。
- npm run test:e2e：桌面/手机尺寸下的导航位置、搜索收藏、手势、弹层、单一导览、GPS 与导览图层隔离。
- npm run build：类型检查和生产构建。

自动化使用 Chrome 与模拟设备坐标；不代替 iOS/Android 微信真机、景区现场或测绘精度验收。活动、营业时间、餐厅价格仍为演示数据。

# 濮院建筑外观核对

日期：2026-11-18。用途：支持参考图的建筑描摹与地标重绘；不是建筑测绘、层数鉴定或地理定位验收。

## 主要结论

1. **寺塔不宜替换成常规暗木七层楼阁塔。** 原图下半部是密集层檐、赭褐塔身和浅色多边形基座，上部后方还出现高而近直立的深灰量体。官方“游客中心码头”照片中的真实高塔则为浅石色、细长多边形塔身、密集近等间距层檐及顶部细刹。二者表现不同，不能把原图黑色上部的真实结构说成已经证实，也不能凭画面猜总楼层。
2. **禅意酒店应保留宽大方形外圈屋面与内部折转庭院。** 官方“梅尚度假酒店”航拍和文字，提供了比通用空心回字院更具体的参考：外侧宽大坡屋面、明显水平檐带、深色格窗立面、内部交错的绿色小庭院。官方称主楼外观由传统“卍”字纹样延展。
3. **游客中心是复杂组团，不是一栋对称大殿。** 原图可见白墙灰瓦外围、阶梯式山墙、浅蓝玻璃顶、灰色内院，以及向南伸出跨水的两列廊屋和南端门屋。官方码头照片支持“长条木构临水立面、灰瓦廊棚、石墩跨水”的外观，但没有展示原图全部玻璃顶，不能凭该照片补全遮挡区域。

## 寺塔：原图与现状照片应分别处理

### 原图可直接观察的形状

参见 [source-tower.png](../references/architecture/source-tower.png)。裁图来源为用户图片的像素框 `[865,440,975,615]`，放大仅用于观察，没有新增细节。

- 基座明显宽于塔身，浅色多边形阶梯向外展开，靠近水岸。
- 下段有偏赭褐色的实墙/塔座；往上是密集、近水平、暗色的檐线。
- 层檐的横向出挑较小，塔身整体细长，不是每层逐级明显收尖的宽木楼阁。
- 顶部后方出现一段较高、接近直立的深灰形体，顶缘不规则，只有很小的顶部突起；原图看不出一个清楚、细长的传统塔刹。
- 单张低分辨率透视图无法分辨该深灰形体与前方密檐段是同一构筑物、画法省略还是遮挡叠加，**不为它编造结构解释**。

源图复刻目标下，优先保留原图可见轮廓、密檐节奏和上下色块关系。不能为了“像一般宝塔”而增加宽大飞檐、统一尖顶和自定的七层结构。

### 官方照片提供的现状参考

`official-visitor-wharf.jpg` 中背景高塔具有浅石色外观、长而窄的多边形塔体、下部较长的实墙段、上部密集重复的檐口，以及短亭形顶与细刹。酒店官方航拍的背景也能看到类似密檐塔。

这能支持“采用石色、细长、密檐的造型语言”，不能支持“原图深灰上半段就是现状塔上半段”的断言。照片不是建筑正投影；没有正式层数说明时，不写楼层数字、不通过灯带数推断内部楼层。

官方魔方塔照片展示的是近矩形黑色屏幕/方块表皮装置，且文字明确地点为美术馆广场。其存在只说明园内确有另一类现代深色塔状构筑物，**不能拿它来填补原图不清楚部分的身份**。

## 禅意酒店：外圈、内院、立面三者同时保留

原图 [source-zen-hotel.png](../references/architecture/source-zen-hotel.png) 的主体是深灰大方形围合屋面，外侧有明显宽檐与红褐立面；内部不是一块空草坪，而是有折转、错位的小建筑与绿色院地。基底附近有环绕水体。

官方梅尚度假酒店介绍原文：

> 酒店以“禅文化”为主题……主楼外观由中国传统纹样“卍”字为基础设计延展，并融以江南园林景观。

官方航拍可见：宽大的外圈坡屋面、上下一组突出的水平屋檐、深色纵横窗格，中心的数个较小绿色庭院/屋面错开排列。该形态与原图“禅意酒店”具有强对应性，但原图名称与现行酒店名称不同，本轮以外观对照支持描摹，不擅自更改应用名称或把照片当成精确 footprint。

绘制时优先表达外圈宽厚屋面、内部折转构图、密集竖向窗格和深浅层次。不要改成四个互不相连的小殿，不要把内院清空，也不要把所有屋面画成相同大小的尖屋顶。

## 游客中心：保留玻璃顶与廊桥的组合

原图 [source-visitor-center.png](../references/architecture/source-visitor-center.png) 可见：

- 外围白墙灰瓦形成不完全规则的院落边框，屋脊长度和朝向并不统一。
- 内院有浅蓝色、带分格线的玻璃坡顶体量；不能一律换成传统黑瓦。
- 朝水一侧有连续阶梯式山墙；两列狭长屋顶向南跨过水面，南端连接更高的门屋/横向屋体。
- 灰色铺地与浅蓝水面之间的界面清楚，廊桥不能落在填满的“广场”上。

官方码头照片显示更近距离的深色木构临水立面、长檐、栏杆和石墩。该照片可用于材料和檐部细节，不能证明原图内院玻璃顶的全部构造。应由原图保持俯视组团关系，用照片补充可见材料。

# 全园构件细化

## 接续修正：形体与源图明暗

2026-11-18 接续开发时重新对照放大原图，修正两处形体偏差：北更楼上部恢复为深色木构、叠檐和下层开间，底部保留石台与窄阶，移除上一轮自行补出的石墙拱门；妆楼的高立面移回右侧高楼位置，避免压住左边的低矮民居，梁线与窗格沿原图倾斜。

全园可见表面增加源图明暗处理。`scripts/art/source_relief.py` 在已有表面范围内读取原图灰度，提取色调分区和长墨线，保留原有坡面、木梁与立面暗部；屋面先按表面遮罩平滑，避免相邻白墙渗入，细小的深色瓦面与木构笔触另行保留。附加的瓦片纹理降低强度，让原图形体优先。设计师之家两座长屋另按可见屋脊区分双坡；酒店的折转内院补充屋面收口、廊面与庭院材质；寺塔增加石质分面与檐下阴影。

19 个地标与 24 块街巷图层均重新输出。地面、水系、地点锚点和原图对照沿用已有版本。提取表面的几何校验值继续为 `4e472632940b319d0e032969232e80c7031d63ddbcf04efa23b1d64bad32085b`；材质补充数量见 `references/architecture/finishing-audit.json`。色调分区与墨线属于图像观察，不代表新增建筑、窗门数量或现场测量。

源图、修改前与修改后对照图保存在 `artifacts/relief-*.jpg`；修改前图在本次接续开发时存档。它们用于美术核对，浏览器测试另验证点选、缩放、目录、外围与定位视图。

手机截图核对还确认：建筑图片与细赏状态的 CSS `drop-shadow` 会使 Chrome 中缩放后的建筑细节变软。已移除这两层滤镜，保留图片内绘制的檐影、明暗和键盘焦点边框。开启/关闭滤镜的受控截图见 `artifacts/clarity-comparison.jpg`；放大细节现在直接由高分辨率素材显示。

## 上一轮细化

2026-11-18。本轮在已有全园轮廓层上继续处理各组团和普通民居的细部，没有改变道路、水系、地点锚点或地理数据。

## 全园处理

所有1025个已提取的建筑表面进入统一的细化流程。灰瓦与金色瓦面增加瓦当、叠瓦、贴近轮廓的檐影和明暗变化；窄墙面增加墙脚与收口；原有木构表面增加边框、接缝、细木格和栏杆纹样。

新增 enrich-architecture.py 从参考图读取可辨认的亮线和深色区域，得到567条屋面亮线、511块屋面阴影及2处满足保守识别条件的窗洞。它们是美术参考标记，不是新增建筑或经实测的构件。脚本校验轮廓点、孔洞、范围及归属在细化前后保持一致。

对于不能可靠识别的窗门，不把空白墙面当成可随意开窗的区域。木格纹样等装饰被限制在已存在的木构表面之内，标签遮挡仍然保留。

## 实现与交付

- scripts/art/surface_finishes.py：统一构件处理及组团材质差异。
- 此阶段北更楼与妆楼的独立占位画法已由 `src/data/street-houses.json` 与 `scripts/art/street_houses.py` 的分层屋体、立面和石台替代。
- references/architecture/finishing-audit.json：来源、数量与几何校验摘要。
- 所有19个地标组团和24块街巷图层重新输出透明细节图与预览图。
- 详情图片现在合成周边建筑图块，避免相邻屋面在详情里遗漏。
- 渲染器按源图内容缓存生成结果，未变化的资产可跳过重绘。

运行 npm run art:trace 会依次提取轮廓和细化标记；npm run art:models 重建图片；npm run art:reference 更新地面与完整详情图。完整流程仍为 npm run art:generate，美术依赖见 scripts/requirements-art.txt。

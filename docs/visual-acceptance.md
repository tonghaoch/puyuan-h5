**如何判断局部修改是否足以追上目标。** 可在原命令额外传 `--ink-budget`。它不更改阈值、取景、舍弃区或严格得分。记交集为 `I`、并集为 `U`，达到 0.85 等价于 `17U − 20I ≤ 0`。少漏一个有效点使左式减 20，移除一个多画点使它减 17。报告中的 `remainingDeficitTwentieths` 是这一整数，不是另一种相似度。

第三批[分块诊断](../artifacts/park-085/pass-3-budget/ink-budget.json)得到 `17U − 20I = 1,020,992`。即使允许在每个 8×8 格子内完美重排墨点，只要各格各区的墨量不变，理论上限仍只有 **.829789**；另外还有 29,147 个漏点和 18,550 个多画点无法在格内配对。这不是说每个点都错位八像素，也不是放宽验收半径。它说明不能只靠挪细线：需要重新观察整株、整段屋脚或岸面的形态及留白。

另在无原图副本里分别抽去十类前景画法，逐份从 SVG 重新编码并叠回相同底图，再与全量图比较。[逐族结果](../artifacts/park-085/pass-3-budget/cohort-impact.json)与[西北](../artifacts/park-085/pass-3-budget/cohort-nw.jpg)／[西南](../artifacts/park-085/pass-3-budget/cohort-sw.jpg)样窗显示：55 株花木目前让 896 个判断变对、1,859 个变错；36 株层枝类则让 3,632 个变对、2,478 个变错。十类覆盖 536 株分株和 134 个未拆旧树团。每项实验都从相同全量版出发，互有遮挡，**不能相加或作为删树理由**。开发与验证分开选真实花木、阔叶冠和石岸段，以形态和整园严格分数双重复核。

- `visual-acceptance-v1.json` 固定参考图哈希、`e240463` 的园界、印刷标签及题字遮罩、原图取景 `[30,180,1550,1420]` 和 19 个地标诊断窗。园界、原图、阈值不能随某次出分改变；可比范围包含水道、白墙、树木、街巷和所有其他园内可见画面。印刷字后的补绘不冒充原图证据。
- 原生场景按主图的顺序合成地形、岸边物件、街巷建筑、地标、前景植物，按 3 倍尺寸合成后用 Lanczos 回到原图分辨率。以 `(-30,-180)` 登记图面坐标，不做自动找齐或逐窗移动。
- 同时对两侧使用 OpenCV 的 RGB 转灰度，严格 `<145` 算暗。IoU = 同时为暗的像素 / 任一侧为暗的像素；没有像素容差，不奖励同时明亮的背景。有效范围始终是 **833,439** 像素。每个 128 像素网格不重叠，网格计数必须恰好加回全园。地标窗口不参与加权。
- 每轮 `alignment.json` 同时记录协议与遮罩的 SHA-256、计数、窗和误差网格；`errors.png` **红=少画暗部、蓝=多画暗部**，灰色域外不计分。功能回归、无原图重建和对照目视另做，不用其中任何一项替代全园分数。

## 复现

在项目目录中，准备 `scripts/requirements-art.txt` 的 Python 环境、项目 Node 依赖和可用的 Chromium。生成命令不需要 `references`；只有离线验收与观察才读取参考图。以下命令使用当前工作区或另一个由相同作者数据生成的场景：

```sh
npm run art:geometry && npm run art:generate
python3 -m unittest discover -s tests -p 'test_*.py'
python3 scripts/review-park-alignment.py --out artifacts/park-085/check --diagnose
python3 scripts/review-park-alignment.py --root /path/to/clean-rebuild --out artifacts/park-085/check-rebuilt --diagnose
python3 scripts/compare-art-rebuild.py --strict --rebuild /path/to/clean-rebuild --out artifacts/park-085/check-rebuild.json
cmp artifacts/park-085/check/alignment.json artifacts/park-085/check-rebuilt/alignment.json
cmp artifacts/park-085/check/distance-context.json artifacts/park-085/check-rebuilt/distance-context.json
cmp artifacts/park-085/check/layer-context.json artifacts/park-085/check-rebuilt/layer-context.json
npm test && npm run build && npm run test:e2e
```

独立重建从空目录开始，仅复制 `scripts/`、`package.json` 和 `src/data/` 中的八份输入：`landmark-structures`、`reference-map`、`roof-guides`、`street-houses`、`street-observations`、`town-architecture`、`town-completions`、`town-landscape`（扩展名均为 `.json`），链接已安装的 `node_modules`。**不复制** `public/`、`references/`、旧生成清单或缓存。在该目录执行上述生成命令，再回到项目执行比较。可用已推送版的独立工作区作为 `--root` 复查基线，旧版无需包含新的验收脚本。误差掩膜 SHA-256 为 `53cdb737f210cfaf4dbe5375758f5a44ea524de63602ab79fa2f20da310c512a`。

# 全园建筑轮廓与实景校正

2026-11-18。本轮替代先前四个通用建筑样片，覆盖参考图中的全部18个标注地点；寺塔单列，共19个独立可查看组团。未命名的街巷建筑另由24个透明图块覆盖。

后续已继续完成构件细化，见 [全园构件细化](architecture-finishing.md)。

## 还原依据

- 以用户原图中实际可见的轮廓确定屋顶、白墙、木构与玻璃体量的位置。使用原始像素坐标，不重新排布街巷或套用统一院落模板。
- 19个组团采用不同的实际轮廓：游客中心保留玻璃体量和跨水廊屋；酒店保留宽大方形外圈和折转内院；美术馆、设计师之家保留纵长体量；翔云观保留斜向院落；龙湾街保留围绕水面的建筑；水上舞台保留弧形看台和小型平台。
- 景区官方照片进一步核对了浅石色密檐塔、福善寺木构与酒店内院。原图中的塔上部深色量体身份不清，手绘导览采用官方实景照片支持的浅石密檐外观，原图对照保留原始剪影。没有把层檐绘制数量当成实测楼层数据。
- 官方来源、照片、原图裁框与逐组团观察见 [建筑参考核对](architecture-reference-review.md)。

## 覆盖与图层

轮廓提取最初包含细长河岸、阴影等干扰。排除这些干扰后，保留1025个可见建筑表面轮廓：337块灰色屋面、3块金色屋面、357块木构表面、325块墙面和3块玻璃表面。这是图面构件计数，不能解释为1025栋建筑。

references/architecture/visible-surfaces.json 保留每个轮廓的原图点、空洞、颜色、方向和归属。每个构件只归属一个组团；其他构件进入背景建筑图块。coverage-summary.json 和 surface-coverage.jpg 可以核对覆盖范围。

在这些轮廓内细化瓦片方向、瓦面明暗、木饰面、墙面纹理、窗洞与玻璃骨架；地标另补绘明确的檐口、外圈屋面、内院折转与石阶。打印标签继续保留并位于建筑细节图层之上；不使用模糊填充代替被遮挡的未知建筑，也不宣称恢复了原图里不可见的真实细节。

原始照片和地图未被覆盖；原图对照视图保持可用。地理数据、GPS投影和地点锚点没有因美术改造而改变。建筑位置仍在插画坐标中，不构成全园测绘模型。

## 运行时与交互

- 命名组团以高分辨率透明 WebP 展示，保留可编辑 SVG。
- 全园视野使用较轻的预览图，放大后切换细节图。
- 组团和街巷图块均按当前视野挂载；保留连续草地、外围拖拽和返回古镇功能。
- “古建细赏”现有19处目录，可以直接选择，也可以顺序浏览。
- 点击建筑进入对应地点详情；在建筑上拖动仍移动地图。
- 详情图片组合建筑与周围地面，避免将透明表面误当作一栋悬空模型。

## 重建方式

美术处理需要 Python、Pillow、NumPy 和 OpenCV；建筑渲染需要 Playwright/Chrome。日常运行直接使用已有资产，无需安装这些美术依赖。

    python3 -m venv .venv-art
    source .venv-art/bin/activate
    pip install -r scripts/requirements-art.txt
    npm run art:generate

也可分步骤执行：

    npm run art:trace
    npm run art:models
    npm run art:meadow
    npm run art:reference

trace-architecture.py 提取原图构件；generate-landmarks.py 和 art/site_details.py 生成矢量图；render-landmarks.mjs 输出透明图片；prepare-reference-map.py 保留原图和标注，准备连续地面；finalize-architecture.py 生成低缩放预览和详情场景。

检查包括全地点覆盖、构件单一归属、资源完整性、目录选择、低/高细节切换、地图模式隔离及原有交互。全园可见部分已覆盖；文字遮挡和原图无法辨认的细部不冒充已经准确还原，整套插画也不等同于现场测量。

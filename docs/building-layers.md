# 精细建筑与连续外围

2026-11-18。本文记录第一批四个样片与外围草地的实现背景。当前已扩展为19个建筑组团和全园街巷图层，见 [全园建筑与实景校正](whole-town-architecture.md)。

## 建筑资产

src/data/landmark-models.json 保存每个建筑对应的地点、原图像素范围、地面修饰范围、源文件和运行时图片。位置继承原图平移量，未改动地点坐标或地理数据。

scripts/art/architecture.py 提供统一视角的墙面、木构、窗格、瓦面、重檐、台基、灯笼与植物绘制。scripts/generate-landmarks.py 分别组合连廊与玻璃中庭、七层塔、重檐正殿、方形庭院。

建筑是根据参考图外形与组团制作的风格化 2.5D 视觉重建。原图被标签遮挡的部位做了装饰性表达；没有把窗格、楼层或入口称为经过现场测量的建筑数据。当前只重建这四个样片，其他古镇建筑仍沿用参考图。

可编辑 SVG 位于 public/art/landmarks，scripts/render-landmarks.mjs 在独立浏览器中以 3 倍尺寸渲染为带透明通道的 WebP。页面加载 WebP，避免缩放时重复绘制数千条瓦片与窗格线条；光点动效和点击区域单独保留。

## 图层顺序

1. 跟随地图镜头的可重复草地纹理。
2. 按视野加载的外围草丛、树木、石景块。
3. 原图布局的地面、水系和普通建筑，外围透明渐变，样片位置经过限定范围修饰。
4. 独立建筑图片及局部灯光。
5. 水面、游船、花瓣与飞鸟效果。
6. 地点 pins、应用操作界面。

原图对照不绘制重建建筑，仍可使用同一镜头检查原图形态。真实路网与影像不绘制这片装饰性草地，也不使用手绘建筑坐标。

## 草地与镜头

保留原始 SCENE=1520×1240，手绘镜头的可拖动范围向四边各扩展1600个场景单位。扩大的是镜头探索范围，不是对原图或经纬度重新缩放。

外围只有草纹、疏林、石景与柔和色块，没有新增建筑或可导航设施。地面纹理可重复延展，外围植物拆成768像素的小块，MeadowLayer 仅挂载当前视野附近的块，避免创建一张巨大的画布。

手绘最大缩放增至3倍；真实地理视图保持自己的镜头范围和缩放上限。古镇离开视野后出现“回到古镇”，原有重置按钮仍然可用。

## 交互与验证

右侧“细看古建”按钮或细赏面板的下一处按钮可以逐个浏览样片。细赏时暂时隐藏对应地点的 pin，避免遮住屋檐和院落。点击建筑打开相同地点详情；在建筑上拖动或缩放不触发点击详情。

验证包含镜头边界、视野裁切、四种地图坐标隔离、模型点击/拖动、外围探索与返回，以及原有搜索、收藏、底部导航和定位流程。自动化使用 Chrome 的桌面/手机尺寸；微信真机性能仍需实际设备验证。

## 重建命令

    npm run art:models
    npm run art:meadow
    npm run art:reference

运行整个美术管线可用 npm run art:generate。需要 Python/Pillow 和可供 Playwright 使用的 Chrome/Chromium。日常开发直接使用仓库中的现成资产。
